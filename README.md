# TJ Home

A hub of tiles linking to everything I've made: https://kodabigvoice.github.io/tj-home/

Small pages without their own site live here in their own folders:

| Folder | Page |
|---|---|
| `wheel-of-names/` | Wheel of Names |
| `board-calculator/` | Board Calculator |
| `pdf-switchyard/` | PDF Switchyard |
| `hyde-park-3d/` | Hyde Park Circuit 3D |
| `hyde-park-lap/` | Hyde Park Lap Viewer |
| `vic-lap/` | VIC Lap Viewer |
| `engine-note-lab/` | Engine Note Lab |
| `family-tree/` | Family Tree |
| `lunch-queue/` | Matchday Queues |

Apps with their own site (PMU, Morning Slide, Crooket, MusicLAMDA, Simple Track Builder, Vobiscum Configurator) are only linked.

**Adding a tile:** add one line to `APPS` in `index.html` (and optionally a picture to `PICS`).

All pages on `kodabigvoice.github.io` share browser storage, so each app uses its own storage key names.
